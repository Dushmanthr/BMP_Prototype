# Hero Section Image

Place your manual hero image here.

### How to use:
1. Copy your desired image file here and name it **`hero-image.jpg`** (or `.png` / `.webp`).
2. If you use a different filename or format (e.g. `hero-banner.png`), update `src/config/heroConfig.ts`:
   ```ts
   export const HERO_IMAGE_CONFIG = {
     src: '/images/hero/hero-banner.png',
     ...
   };
   ```
3. The image will automatically display on the Landing Page hero section.
